# Tsuba 界面样式标准

v3，2026-10-28。风格：**实色石墨灰的安全软件仪表盘**。布局感觉参考 Protectstar Antivirus AI 一类的 Mac 安全软件：一屏仪表盘、主图加状态加主按钮、一排快捷操作、一排磁贴、底栏。细节遵守 Apple Human Interface Guidelines（macOS）。图形和文案都是 Tsuba 自己的，不照搬别家的品牌元素。

实现：样式都在 `src/App.css` 的 token 里，组件只引用 token，不写裸色值。

> 历史：v1、v2 是液态玻璃（原生毛玻璃 + 半透明卡片）。玻璃叠在页面上以后几乎看不出透明，还要开 macOS 私有 API，所以 v3 换成实色。`--glass` 等变量名保留了下来，现在都指向实色面板。

## 0. 原则

1. **一眼看懂状态，一步做到主操作。** 首页回答两个问题：现在受不受保护？有没有要我处理的事？其他功能从磁贴进入。
2. **实色面板，层次靠明暗和细线。** 不用透明、模糊和大投影。深色是主场景，浅色是同一套结构换一组 token。
3. **颜色只表达意思。** 青色是主操作；绿、琥珀、红只表示放行、提醒、拦截，并且总配文字或图标；“威胁情报”磁贴的绿色表示“已更新”；品牌朱色只用在标志上。
4. **安全状态一眼可辨。** 守护暂停时，在任何一页都要感觉到“现在没有保护”。
5. **证据先要读得清。** 命令、路径、代码片段放在更深一档的“凹槽”底上，用等宽字体。

## 0.5 标志

**刀与护手**：Tsuba（鍔）就是日本刀的护手，挡在刀刃和握刀的手之间，对应“在代码运行之前替你挡一下”。标志就是这把刀：有弧度的钢刃、铜套、黑漆圆盘护手配金边、缠绳刀柄，斜放 35°（竖直放容易被看成十字架）。

- **App 图标**：朱红渐变底板 + 刀，按 macOS 图标网格（1024 画布、824 见方圆角方形）。由 1024 主图用 `pnpm tauri icon` 生成全套尺寸，放在 `src-tauri/icons/`。
- **界面里的小标志**（`TsubaMark`）：朱红圆角方块（`--brand`）里一把白色的刀剪影（`KatanaGlyph`），和 App 图标同一个样子。
- **菜单栏**：同一把刀的单色剪影做模板图标（`icons/tray-template.png`），护手画成厚圆盘，18px 下也认得出是刀；系统按菜单栏深浅自动着色。
- 首页插图屏幕中央也是这把刀，右下角状态徽章：守护中绿勾，暂停红叉。

## 1. 布局

```
┌ 标题栏 40px：红绿灯 · ‹ 返回（不在首页时） · ……………… Tsuba / 暂停时的红色恢复按钮 ┐
│                                                                                      │
│  内容区（首页是仪表盘，其他页是详情页，最大宽 880–920px，居中）                        │
│                                                                                      │
└ 底栏 40px：TSUBA 标志 · 当前判断方式 ………………………………………………………… ⚙ 设置 ┘
```

- **没有侧边栏。** 首页 → 磁贴 / 快捷操作 → 详情页 → 标题栏“‹ 返回”。⌘1–4、⌘, 快捷键照旧。
- **仪表盘**（自上而下）：
  1. 主区：左边插图（电脑屏幕上跑着陌生命令，中间是刀镡标志），右边状态胶囊、标题、四道防线的勾选状态、主按钮“检查一个文件夹”、上次提醒。整个窗口都可以拖文件进来检查。
  2. 快速操作：虚线框，标签压在框线上，三个等宽按钮：扫描文件夹、全面体检、检查记录。
  3. 磁贴：四个等宽卡片：需要处理的提醒（红色标题）、隔离区、白名单、威胁情报（绿色实底）。
- **详情页**：最上面是头部卡片（`PageHeader` 传 `icon`）：56px 带颜色的图标底块、状态胶囊、标题和说明、右侧主操作，下面一排关键数字（比如扫描页的常用文件夹、定期扫描、隔离区、白名单）。状态色跟着结论走：正常绿、有问题琥珀、暂停红、进行中青。下面是分组列表和卡片。检查记录是左右分栏：左边列表栏比内容区暗一档。
- **体检页**：没跑过也有内容：头部显示上次体检的时间和结论（记在本机），每张检查卡片列出具体查什么，描述必须和引擎实际检查的一致。
- **防线开关在设置页最前面**；仪表盘只显示每道防线开没开，点一下跳到设置。

## 2. 颜色

### 表面

| token | 深色 | 浅色 | 用途 |
|---|---|---|---|
| `--window` | `#2b2c30` | `#f4f4f6` | 窗口、内容区底色 |
| `--bar` | `#25262a` | `#ececef` | 标题栏、底栏、检查记录的列表栏 |
| `--band` | `#323338` | `#ebebef` | 快速操作的底 |
| `--panel` | `#36373c` | `#ffffff` | 卡片、分组列表、磁贴 |
| `--raised` | `#3e3f45` | `#ffffff` | 按钮、悬停的磁贴、选中项 |
| `--well` | `#222327` | `#f7f7f9` | 命令、代码片段、输入框（凹槽） |

深色模式的面板顶部有 1px 白色 5% 的内高光，四周 1px 黑色 28% 的描边。浅色模式只用 1px 的淡描边。

### 文字和线

| token | 深色 | 浅色 |
|---|---|---|
| `--text` | `#f2f2f4` | `#1b1b1f` |
| `--text-2` | `#c6c6cc` | `#4b4b52` |
| `--text-3` | `#9c9ca4` | `#75757d` |
| `--line` | 白 7% | 黑 8% |
| `--dash` | 青 42% | 青绿 40%（快速操作的虚线框） |

### 意义色

| token | 深色 | 浅色 | 用途 |
|---|---|---|---|
| `--cta` | `#7cc4d6`（深字 `#10313a`） | `#2f8fa6`（白字） | 主操作、选中、键盘焦点 |
| `--allow` | `#6fd18f` | `#1f8a50` | 放行、守护中、开关打开 |
| `--warn` | `#f0b44c` | `#a96400` | 提醒、防线没开 |
| `--block` | `#ff7a6b` | `#c62f22` | 拦截、删除、已暂停（文字和图标） |
| `--alarm` | `#d0392b` | `#c62f22` | 红底白字的按钮（恢复守护、确认删除） |
| `--intel` | 绿色渐变 | 绿色渐变 | 只用在“威胁情报”磁贴 |
| `--brand` | `#e0563c` | `#c2412a` | 只用在品牌标志 |

白字只放在 `--cta`（浅色模式）、`--alarm` 和 `--intel` 上。深色模式的青色按钮用深字。

## 3. 字体

系统字体：SF Pro + 苹方。等宽：SF Mono。基准 13px。

| 样式 | 字号 / 行高 | 字重 | 用途 |
|---|---|---|---|
| Display | 26 / 31 | 700 | 仪表盘标题，全应用只有一处 |
| Title | 24 / 30 | 700 | 详情页标题，每页一个 |
| Headline | 17 / 24 | 600 | 报告结论 |
| Tile | 13 / 18 | 650 | 磁贴标题、快速操作按钮 |
| Section | 13 / 18 | 600 | 分区标题（`--text-2`） |
| Body | 13 / 20 | 400 | 正文 |
| Caption | 11.5–12 / 17 | 400 | 磁贴说明、元数据、底栏 |
| Label | 10 / 14 | 650，字距 0.16em | 压在框线上的分组标签（“快速操作”） |

数字一律 `tabular-nums`。命令、路径、错误信息不截断（仪表盘上的“最近一条”除外，点进去看全文）。

## 4. 圆角和间距

| 值 | token | 用在 |
|---|---|---|
| 14px | `--r-xl` | 拖文件进来时的落点框 |
| 12px | `--r-lg` | 分组列表、卡片、快速操作框 |
| 10px | `--r-md` | 磁贴、代码块、提示条、列表项 |
| 8px | `--r-sm` | 按钮、输入框、图标底块 |
| 胶囊 | `--r-pill` | 状态胶囊、结论标签、开关、标题栏的恢复按钮 |

间距用 4px 节奏：4 / 8 / 12 / 16 / 20 / 24 / 32。仪表盘各区块之间 18，磁贴之间 12，详情页分区之间 28，页面左右 24–40。

## 5. 动效

- 时长 160–240ms（入场 380–420ms），曲线 `--ease: cubic-bezier(.2,.8,.2,1)`。
- 入场：首页的主区、快速操作、四块磁贴依次上浮出现，间隔 40ms；详情页的头部卡片和检查卡片同理。
- 磁贴和快速操作悬停浮起 2px 加阴影，按下回落；主按钮悬停光晕变亮。
- 守护中时状态点缓慢呼吸（2.8 秒一次），暂停或部分防线没开时不呼吸。
- 按钮按下缩到 0.97；开关滑块按下拉宽。
- 进行中的任务：卡片底边扫光或转圈，不用整页遮罩。
- 暂停时标题栏的恢复按钮缓慢呼吸（2.4 秒一次）。
- 系统开了“减少动态效果”时全部关闭。

## 6. 交互规范（UX）

1. **互不相干的任务互不打断。** 每个任务有自己的进行中、出错、完成状态，可以同时跑（体检的三项检查）。“全部”只启动还没在跑的。
2. **离开页面不丢进度。** 耗时任务的页面（体检）切走时不卸载。
3. **出错就近显示。** 哪一项出错写在哪一项上。
4. **危险状态要“响”。** 守护暂停时：
   - 仪表盘：插图里的标志变红并打叉，状态胶囊变红，标题“保护已关闭。”，写清哪些东西现在不会被检查，主按钮变成红色的“恢复守护”；
   - 标题栏右上角变成红色的“守护已暂停 · 点击恢复”，在任何一页都能一键恢复；
   - 窗口顶部压一层淡红光。
5. **删不回来的操作要点两次，并且和其他按钮隔开。** 放在工具栏最右边；第一下变成“再点一下，永久删除”，三秒内再点才执行。能撤销的操作（移入隔离区）优先。
6. **删除要有护栏。** 只能删记录里那个具体的文件或项目；家目录、家目录下的一级目录、系统目录一律拒绝。护栏在引擎里（`quarantine::delete_path`）。
7. **每个操作都有反馈。** 做完给一句提示（toast），失败时写明原因和下一步。
8. **不打扰。** 仪表盘只摆一个主操作；警告只在真的有事时出现，不轰炸。

## 7. 组件

### 按钮

圆角 8px，高 30px（快速操作 36px，仪表盘主按钮 38px），字重 500–650。

| 变体 | 外观 | 用法 |
|---|---|---|
| 默认 | `--raised` 实底 + 细描边 | 次要操作 |
| `primary` / `cta` | `--cta` 实底 | 一屏最多一个主操作 |
| `cta-alarm` | `--alarm` 实底，白字 | 恢复守护 |
| `danger` | 默认外观，文字 `--block`；`is-armed` 时 `--alarm` 实底 | 删除类，点两次 |
| `link` | 无底 | 行内轻操作（暂停守护、移除） |
| `back` | 默认外观，小号 | 标题栏的“‹ 返回” |
| `icon-button` | 无底，28px | 必须有 `aria-label` 和 `title` |

禁用：不透明度 0.4。键盘焦点：3px `--focus` 外环。

### 状态胶囊

高 24，胶囊形，状态色 soft 底 + 1px 状态色描边 + 发光圆点 + 文字。守护中是绿色，部分防线没开是琥珀，暂停是红色。

### 磁贴

`--panel` 实底，圆角 10，最小高 84，内边距 13×14。标题 13/650 带 14px 图标，说明 11.5 `--text-3`。悬停换 `--raised`。整块可点。

### 快速操作

1px `--dash` 虚线框，`--band` 底，圆角 12；标签“快速操作”压在上框线正中，背景用 `--window` 盖住线。里面三个等宽按钮。

### 输入框、开关、分段控件、分组列表、结论标签、提示条

- **输入框**：`--well` 凹槽底，圆角 8，高 32，聚焦时边框变 `--cta`。
- **开关**：38 × 22，开为 `--allow`。
- **分段控件**：`--fill` 凹槽底，选中段 `--raised`。
- **分组列表**：`--panel` 卡片，行最小高 54，行间内缩细线。
- **结论标签**：胶囊，状态色 soft 底 + 状态色文字 + 图标，永远配文字“放行 / 提醒 / 拦截”。
- **提示条**：状态色 soft 底，圆角 10，放在出错位置附近。

## 8. 浅色 / 深色

- 设置 → 外观：跟随系统 / 浅色 / 深色，保存在本机（`localStorage` 的 `tsuba-theme`）。
- `<html data-theme="light|dark">` 由 `src/theme.ts` 在渲染前写入，同时设置窗口外观（标题栏、红绿灯、系统弹窗），并监听系统切换。
- 每次改样式两套都截图；开发预览地址加 `?paused` 可以直接看暂停状态。

## 9. 可访问性

- 正文对比度 ≥ 4.5:1，`--text-3` 只用在 11.5px 以上的辅助信息。
- 所有交互元素都有键盘焦点样式；图标按钮有名字；⌘1 回首页、⌘2–4 进各页、⌘, 设置，上下键切换检查记录。
- 系统开了“减少动态效果”时没有动画。
